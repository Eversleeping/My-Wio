# 运维参考

日常入口见[用户手册的操作中心与监控](USER_GUIDE.md#14-操作中心监控与告警)，安装/升级见[生产部署指南](PRODUCTION_DEPLOYMENT.md)。本文补充诊断、回执和保留策略。

## 分清三条链路

- **浏览器 → 控制面**：HTTPS 与 WebSocket。页面“实时连接”只确认这条链路，重连后会补取资源状态。
- **Agent → 控制面**：出站 gRPC 双向流。核对 Agent 在线、最近心跳、公开 URL、TLS 及代理 h2c 配置。
- **Agent → Git / 模型服务 / 下载源**：单独的出站访问。Agent 在线但模型或 Git 失败时，检查对应网络、认证及进程环境。

外部 Agent 默认每 15 秒上报心跳和指标、每 2 分钟更新仓库清单。主机侧可查看：

```bash
systemctl status wio-agent
journalctl -u wio-agent --since '30 minutes ago'
```

内置 Agent 与控制面同进程，查看 `controlplane` 容器日志。不要将外部 `wio-agent` 服务的检查命令用于容器内置 Agent。

## 操作中断与回执

操作中心对以下操作提供中断，要求 Agent **0.2.96+**：

| 操作类型 | 内容 |
| --- | --- |
| `git.workspace.inspect` | Git 信息检查 |
| `inventory.scan` | 仓库发现 |
| `workspace.files` / `workspace.changes` | 文件与变更扫描 |
| `workspace.file.preview` / `workspace.diff.preview` | 文件与差异预览 |

点击后显示“中断中”，目标操作保持原状态。Agent 取消执行上下文并等待退出后才写入取消回执；若恰好已完成，保留实际结果。超过 15 秒没有确认时中断请求可能失败，目标记录保持执行，可重试。

离线时中断排队，重连后优先处理；重复提交复用未完成请求。Agent 重启导致中断回执未返回时，控制面重送并恢复回执。当前 Agent 已无执行实例的遗留操作会保存取消回执，阻止迟到命令重放；该确认只覆盖 Agent 管理的操作，不证明所有外部遗留进程都已结束。

中断扫描/预览会释放对应加载状态，旧请求的迟到结果不覆盖较新快照。AI 任务、部署、升级、凭据和文件写入使用自身控制流程，不由此入口通用取消。

Agent 已完成操作的内存缓存有数量、容量和过期限制；压缩结果回执还持久保存在状态目录的 `operation-results`。控制面重交付同一操作时可返回原结果，避免重复执行。磁盘回执按 **7 天**保留：Agent 启动时和运行中定期清理过期回执（同一次清理也会删除超过 7 天的 `claude/forks/` 快照），超期后同一操作的重交付不再命中回执、可能重新执行；不要把普通缓存清理等同于可以随意删除该目录。

## 扫描与页面刷新

文件变更扫描和 Git 检查等待期间，每 2 秒补查一次结果作为 WebSocket 兜底；完成或离开面板后停止。操作中心存在活动操作时每 3 秒补查。实时事件到达时合并刷新，避免慢网络下反复取消同一请求；离开页面或切换资源会取消旧读取。

PostgreSQL 连接默认 `jit=off`，减少短查询触发 JIT 的额外耗时，不需要修改数据库全局配置。默认最大连接数为 20，可通过控制面环境变量 `WIO_POSTGRES_MAX_OPEN_CONNS` 设置正整数。

## 数据保留

控制面启动时及之后每小时分批清理，避免长期积累占用数据库。策略定义见 [retention.go](../internal/store/retention.go)。

| 数据 | 策略 |
| --- | --- |
| 过期登录会话 | 到期后清理 |
| 监控分钟聚合、部分服务器操作终态通知 | 保留 7 天，保留事件序号水位 |
| 审计日志 | `WIO_AUDIT_RETENTION_DAYS`，默认 0/未设置为永久 |
| 可清理的已结束 Agent 操作 | `WIO_OPERATION_RETENTION_DAYS`，默认永久 |
| AI 会话事件/操作 | 不受通用操作保留策略清理 |
| 协作、部署、容器状态、定时任务依赖的操作 | 保留所需引用记录 |

保留天数必须为非负整数。减少保留时间可能删除历史，先完成备份。Compose 默认未传入这几个可选配置；需通过覆盖文件的 `services.controlplane.environment` 显式注入，只写入 `.env` 不生效。

此策略不清理主机工作区、发布目录、应用卷或 CLI 原生历史；Agent 磁盘回执和 `claude/forks/` 快照由 Agent 自行按 7 天保留清理。备份范围见 [README](../README.md#备份与安全)。
