# 操作中心

操作中心显示 Agent 操作的排队、执行和完成状态。Git 检查、仓库扫描、工作区文件扫描、变更扫描、文件预览和差异预览支持点击「中断」。执行端需更新至 0.2.96 或更高版本；旧版本按钮会提示升级。

点击后显示「中断中」，目标操作仍保留原状态。Agent 取消对应执行上下文并等待任务退出后，控制端才根据真实回执更新为已取消；若任务恰好已完成，则保留原来的完成结果。停止超过 15 秒仍未得到确认时，中断请求失败，目标记录保持执行中，可再次点击重试。

Agent 离线时中断请求排队，重新连接后优先处理。重复点击会复用尚未完成的中断请求。执行中因 Agent 重启而丢失回执的中断请求会自动重送，并一并恢复目标操作的回执。尚未执行或当前 Agent 已无对应执行实例的遗留操作，会保存取消回执，阻止迟到命令在重连或重启后重新执行；记录结果会注明当前 Agent 没有活跃执行实例。该确认范围是 Agent 管理的操作，不包括之前进程遗留的独立子进程。

中断扫描或预览后，对应的加载状态会释放，可重新刷新。旧操作的中断不会覆盖较新请求的快照。任务会话、部署、升级、凭据变更和文件写入继续使用各自的控制流程。
